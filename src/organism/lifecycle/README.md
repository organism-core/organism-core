# lifecycle/

State machine `(a)→(e)` for entity / action maturity: captured →
enriched → reviewed → released → archived (or analogous).

**Phase 3**: lifecycle state machine, written from scratch.

**Separation test ✓** — a client mandate has the same lifecycle
(prospecting → engagement → processing → close → archive). The
pattern is domain-independent.
