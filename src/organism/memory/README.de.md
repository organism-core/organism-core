# memory/

Entity-Memory-Pattern: pro Entity ein Verzeichnis mit `_entity_profile.md`
(YAML-Frontmatter + Freitext) und Sub-Indizes für angehängte Artefakte.
Schema-frei — Felder optional, neue Felder jederzeit erlaubt.

**Phase 1**: Pattern-Implementation, ohne domänen-spezifische Felder.

**Trenn-Test ✓** — Steuerberatung würde Mandanten so verwalten (Mandant
statt Entity, Steuerberater statt Owner). Pattern ist Schema-frei und
generisch.
